1 Bộ cài này dùng để làm gì?

Giúp 2 hay nhiều máy tính "xem chung" một thư mục. Bạn bỏ file vào thư mục trên máy này, máy kia sẽ tự động có file đó.

  • Không còn phải gửi file qua Zalo, Email hay USB.
  • File sửa ở máy nào, các máy còn lại tự động cập nhật theo.
Thư mục sync: C:\Users\Admin\Documents\Sync

Chỉ cần nhớ 3 file

FileKhi nào dùng
Cai-Dat-Sync.cmdCài lần đầu, hoặc thêm máy mới
Huong-Dan.cmdXem hướng dẫn chi tiết (file này)
Khoi-Dong-Sync.cmdBật lại Syncthing nếu bị tắt

Các file .ps1 khác là file hệ thống — không cần mở.

2 Ba điều cần biết trước

Máy cũ / Máy mới

Máy cũ = máy đã cài bộ sync từ trước (ví dụ máy LAPTOP).

Máy mới = máy muốn thêm vào lần này (ví dụ máy thứ 3).

Device ID

Giống "số căn cước" của máy tính — mỗi máy có một số riêng, không trùng nhau.

Muốn hai máy nói được với nhau: máy A phải biết số của máy B, và ngược lại. Thiếu một chiều là không chạy.

Tailscale

Mạng ảo nối các máy lại với nhau. Tất cả các máy phải cài Tailscale và đăng nhập cùng một tài khoản.

Chưa có? Vào tailscale.com tải về rồi đăng nhập.

Xem số Device ID của máy mình: mở trình duyệt gõ http://127.0.0.1:8384 → tìm máy của mình → bấm Show ID.

3 Cài lần đầu (máy đầu tiên)

  1. Kiểm tra có thư mục C:\Users\Admin\Documents\Sync.
  2. Chạy file: Cai-Dat-Sync.cmd
  3. Khi hỏi "Device ID" → nhấn Enter để bỏ qua (vì chưa có máy nào).
  4. Xong. Ghi lại số "DEVICE ID MAY NAY" hiện ra cuối màn hình.

4 Thêm một máy mới

Quy tắc: máy mới "ra mắt" trước, máy cũ "nhận" máy mới sau. Làm lần lượt theo thứ tự dưới đây, không làm ngược.

BUỚC A Trên máy MỚI

  1. Cài Tailscale và đăng nhập cùng tài khoản (xem Phần 2).
  2. Copy toàn bộ thư mục chứa bộ cài (có file Cai-Dat-Sync.cmd) sang máy mới bằng USB hoặc mạng nội bộ.
  3. Mở thư mục đó, chạy: Cai-Dat-Sync.cmd
  4. Khi hỏi "Device ID":
    • Có số của máy cũ bên cạnh → dán từng số vào → Enter. (Làm vậy với từng máy cũ.)
    • Không có số nào → cứ Enter bỏ qua, nối sau cũng được.
  5. Cuối màn hình hiện "DEVICE ID MAY NAY" — đây là số của máy mới.
BẮT BUỘC Gửi số "DEVICE ID MAY NAY" này cho người lo máy CŨ.

Kiểm tra Tailscale đang chạy (biểu tượng nhỏ ở góc phải màn hình).

BUỚC B Trên máy CŨ (làm trên TỪNG máy cũ)

  1. Nhận "DEVICE ID" của máy mới (từ Buớc A).
  2. Chạy: Cai-Dat-Sync.cmd → Enter.
  3. Khi hỏi "Device ID": dán DEVICE ID của máy mới vào → Enter. (Các máy cũ khác đã biết rồi thì Enter bỏ qua.)
  4. Xong. Chuyển sang máy cũ tiếp theo, làm lại từ đầu.

BUỚC C Kết nối lần cuối (làm trên TỪNG máy)

  1. Mở trình duyệt: http://127.0.0.1:8384
  2. Nếu có thông báo "Add device" hoặc thư mục cần xác nhận → bấm Add / Accept.
  3. Kiểm tra thư mục "Documents Sync" hiện chữ Synced.
Thử nghiệm: bỏ 1 file vào thư mục Sync trên máy này — máy kia phải tự động có file đó trong vài giây.

5 Sử dụng hằng ngày

Chỉ cần bỏ file vào C:\Users\Admin\Documents\Sync — mọi thứ tự động chạy, không cần làm gì thêm.

Syncthing bị tắt? Chạy Khoi-Dong-Sync.cmd để bật lại.

6 Nâng cao: đăng ký máy trong file cấu hình

Không bắt buộc. Chỉ làm khi muốn danh sách máy được lưu sẵn, khỏi phải dán Device ID mỗi lần.

Mở hướng dẫn chi tiết
  1. Mở file bằng Notepad: config.ps1 (cùng thư mục với Cai-Dat-Sync.cmd)
  2. Tìm dòng $Peers = @(.
  3. Thêm 1 dòng (bọc trong ngoặc nhọn, ngăn cách bằng dấu phẩy):

    @{ Name = 'Tên máy'; TailscaleIp = 'IP máy'; SyncthingDeviceId = 'DEVICE ID' },

  4. Lưu file, chạy lại: Cai-Dat-Sync.cmd → Enter (nhấn Enter khi hỏi Device ID, vì đã điền trong file rồi).
  5. Làm lại trên từng máy còn lại.
